# ⚡ ElectroHub

> **ElectroHub – Premium Electronics E-Commerce Platform**

ElectroHub is a modern full-stack electronics e-commerce platform built using **Next.js**, **Node.js**, **Express.js**, and **PostgreSQL**. It provides a clean, responsive, and interactive shopping experience with secure authentication, dedicated user and admin portals, and scalable architecture.

---

# 📌 Overview

ElectroHub is designed as a premium electronics shopping platform that demonstrates modern full-stack development practices. It features separate user and admin dashboards, secure authentication, product management, shopping cart functionality, and a responsive user interface.
